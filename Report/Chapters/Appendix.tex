\section{Code Availability}\label{app:code-availability}
The complete Lean development corresponding to this thesis is submitted as a separate archive and is available at: \url{https://github.com/MikkelBrixNielsen/LeanPiLL}

The submitted archive corresponds to the version of the formalisation described in this thesis. The online repository may contain later updates, while earlier experimental versions are available in the repository history. These earlier versions are not part of the submitted artefact. The appendix contains only selected excerpts of the development; the full collection of definitions, auxiliary lemmas, and proof scripts is available in the accompanying codebase.
