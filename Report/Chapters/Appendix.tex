\section{Code Availability}\label{app:code-availability}
The complete Lean development corresponding to this thesis is submitted as a separate archive and is available at: \url{https://github.com/MikkelBrixNielsen/LeanPiLL}

The submitted archive corresponds to the version of the formalisation described in this thesis. The online repository may contain later updates, while earlier experimental versions are available in the repository history. These earlier versions are not part of the submitted artefact.

The appendix contains selected excerpts of the development. These excerpts are typeset to closely reflect the corresponding Lean code. In particular, some Unicode notation and spacing is rendered typographically rather than shown as directly executable Lean source. The complete directly executable Lean files, including all definitions, auxiliary lemmas, and proof scripts, are available in the accompanying codebase.

Since the complete Lean development is submitted as an accompanying archive, the appendix contains only definitions and proof fragments required to support the presentation in the thesis. Full implementations and complete proof scripts are provided in the archived source development.

\section{Common Lean Notation}\label{app:common-notation}
The notation is purely an overloading layer. Each syntactic category supplies its own instance, while the displayed symbols allow the same operation to be written uniformly throughout the formalisation.

\paragraph{Type Classes} The development uses a collection of typeclasses to overload recurring operations across syntactic categories. This allows shifting, substitution, opening, closing, prefix notation, and permutation to be written uniformly for types, processes, environments, hyperenvironments, actions, and labels. The following listing gives the common notation layer used throughout the later appendix excerpts.

\begin{lstlisting}[
  language=Lean4,
  caption={Common typeclasses and notation used throughout the Lean development.},
  label={lst:lean-common-notation}
]
class HasShift (Subject : Type) where
  shift : Subject /-$\to$-/ Nat /-$\to$-/ Nat /-$\to$-/ Subject

notation:max S:max " /-$\uparrow$-/ " d:max ", " c:max => HasShift.shift S d c
notation:max S:max " /-$\uparrow$-/ " c:max => HasShift.shift S 0 c
notation:max S:max "/-$^+$-/" => HasShift.shift S 0 1

class HasSubst (Subject Replacement Target : Type) where
  subst : Subject /-$\to$-/ Replacement /-$\to$-/ Target /-$\to$-/ Subject

notation:max S "{" R " // " T "}" => HasSubst.subst S R T

class HasOpen (Subject Replacement Target : Type) where
  open_ : Subject /-$\to$-/ Replacement /-$\to$-/ Target /-$\to$-/ Subject

notation:max S:max "/-$\dparenL$-/" T " | " R "/-$\dparenR$-/" => HasOpen.open_ S R T
notation:max S:max "/-$\dparenL$-/" R "/-$\dparenR$-/" => HasOpen.open_ S R 0

class HasClose (Subject Replacement Target : Type) where
  close_ : Subject /-$\to$-/ Replacement /-$\to$-/ Target /-$\to$-/ Subject

notation:max S:max "/-$\dangleL$-/" T " | " R "/-$\dangleR$-/" => HasClose.close_ S R T
notation:max S:max "/-$\dangleL$-/" R "/-$\dangleR$-/" => HasClose.close_ S R 0

class HasOpenTwo (Subject Replacement_1 Replacement_2 Target : Type) where
  open_ : Subject /-$\to$-/ Replacement_1 /-$\to$-/ Replacement_2 /-$\to$-/ Target /-$\to$-/ Subject

notation:max S:max "/-$\dparenL$-/" T " | " R1 ", " R2 "/-$\dparenR$-/" => HasOpenTwo.open_ S R1 R2 T
notation:max S:max "/-$\dparenL$-/" R1 ", " R2 "/-$\dparenR$-/" => HasOpenTwo.open_ S R1 R2 0

class HasCloseTwo (Subject Replacement_1 Replacement_2 Target : Type) where
  close_ : Subject /-$\to$-/ Replacement_1 /-$\to$-/ Replacement_2 /-$\to$-/ Target /-$\to$-/ Subject

notation:max S:max "/-$\dangleL$-/" T " | " R1 ", " R2 "/-$\dangleR$-/" => HasCloseTwo.close_ S R1 R2 T
notation:max S:max "/-$\dangleL$-/" R1 ", " R2 "/-$\dangleR$-/" => HasCloseTwo.close_ S R1 R2 0

class HasBracket (Subject Content Result : Type) where
   brack : Subject /-$\to$-/ Content /-$\to$-/ Result

class HasParen (Subject Content Result : Type) where
   paren : Subject /-$\to$-/ Content /-$\to$-/ Result

notation:80 x"/-$\dbrackL\dbrackR$-/" => HasBracket.brack x ()
notation:80 x"/-$\dbrackL$-/"y"/-$\dbrackR$-/" => HasBracket.brack x y
notation:80 x"/-$\dparenL\dparenR$-/" => HasParen.paren x ()
notation:80 x"/-$\dparenL$-/y/-$\dparenR$-/" => HasParen.paren x y

class HasPerm (/-$\alpha$-/ : Type) where
  perm : /-$\alpha$-/ /-$\to$-/ /-$\alpha$-/ /-$\to$-/ Prop

infixr:54 " /-$\sim$-/ " => HasPerm.perm
\end{lstlisting}

\paragraph{Label notation}
The label syntax reuses the bracket and parenthesis notation introduced for process prefixes. Atomic actions instantiate the common \texttt{HasBracket} and \texttt{HasParen} interfaces, while generic instances lift this notation from \texttt{Act} to \texttt{Lbl}. Consequently, the same surface notation can denote either a process prefix or the corresponding transition label, depending on its expected type.

\begin{lstlisting}[
  language=Lean4,
  caption={Notation instances for actions and transition labels. Atomic action notation is lifted to labels so that transition labels mirror process-prefix notation.},
  label={lst:app-lean-label-notation}
]
notation "/-$\mathbf{L}$-/"    => Mu.L
notation "/-$\mathbf{R}$-/"    => Mu.R
notation "USE"  => Mu.USE
notation "DUP"  => Mu.DUP
notation "DISP" => Mu.DISP

@[simp] instance : HasBracket FPName Unit Act where
  brack x _ := Act.one x
@[simp] instance : HasBracket FPName FPName Act where
  brack x y := Act.tensor x y
@[simp] instance : HasBracket FPName Types Act where
  brack x A := Act.output x A
@[simp] instance : HasBracket FPName Mu Act where
  brack x /-$\mu$-/ := Act.muBrack x /-$\mu$-/

@[simp] instance : HasParen FPName Unit Act where
  paren x _ := Act.bot x
@[simp] instance : HasParen FPName FPName Act where
  paren x y := Act.parr x y
@[simp] instance : HasParen FPName Types Act where
  paren x A := Act.input x A
@[simp] instance : HasParen FPName Mu Act where
  paren x /-$\mu$-/ := Act.muParen x /-$\mu$-/

@[simp] instance {S C : Type} [HasBracket S C Act] :
    HasBracket S C Lbl where
  brack s c := Lbl.act (HasBracket.brack s c)

@[simp] instance {S C : Type} [HasParen S C Act] :
    HasParen S C Lbl where
  paren s c := Lbl.act (HasParen.paren s c)

notation:80 x " /-$\leftrightarrow_{\texttt{l}}$-/ " y => Lbl.link x y
notation:70 l " /-$\pp_{\texttt{l}}$-/ " l' => Lbl.par l l'
notation:80 "/-$\tau$-/" => Lbl.tau
\end{lstlisting}

\subsection{Session Types}\label{app:session-types}
This listing gives the core Lean representation of session types. Type variables are represented using the locally nameless approach discussed in \cref{subsec:locally-nameless}, separating free type variables from bound de Bruijn indices.

  caption={Locally nameless representation of type variables and the Lean definition of session types.},

abbrev FTVar := Nat
abbrev BTVar := Nat

  | bound   (x : BTVar)

  | bot
  | tensor      (A B : Types)
  | parr        (A B : Types)

  | amp         (A B : Types)
  | bang        (A : Types)
  | quest       (A : Types)

  | exists_     (A : Types)

\subsection{Processes}\label{app:processes}
This listing gives the core Lean representation of channels and process syntax. Channels are represented using the locally nameless approach discussed in \cref{sec:binding-architecture}, separating free names from bound indices.

\begin{lstlisting}[
  language=Lean4,
  caption={Locally nameless representation of channels and the Lean definition of process syntax.},
  label={lst:lean-proc-basic}
]
abbrev FPName := Nat
abbrev BPName := Nat

inductive Channel : Type where
  | free    (x : FPName)
  | bound   (x : BPName)
deriving DecidableEq, BEq, Repr

prefix:max "#" => Channel.free
prefix:max "$" => Channel.bound

inductive Proc : Type where
  | nil
  | one         (x : Channel) (P : Proc)
  | bot         (x : Channel) (P : Proc)
  | tensor      (x : Channel) (P : Proc)
  | parr        (x : Channel) (P : Proc)
  | cut         (P : Proc)
  | par         (P Q : Proc)
  | selectL     (x : Channel) (P : Proc)
  | selectR     (x : Channel) (P : Proc)
  | amp         (x : Channel) (P Q : Proc)
  | output      (x : Channel) (P : Proc) (A : Types)
  | input       (x : Channel) (P : Proc)
  | server      (x : Channel) (zs : Finset Channel) (P : Proc)
  | consume     (x : Channel) (P : Proc)
  | duplicate   (x : Channel) (P : Proc)
  | dispose     (x : Channel) (P : Proc)
  | link        (x y : Channel)
deriving DecidableEq, BEq
\end{lstlisting}

\subsection{Judgements}\label{app:judgement-basic-definition}
This listing gives the Lean definition of the main typing judgement, including the constructors for the static \pill{} typing relation and the exchange rules used to account for list-based environments.

\begin{lstlisting}[
  language=Lean4,
  caption={The main typing judgement. The judgement \texttt{Typing n P G} states that process \texttt{P} is well typed under hyperenvironment \texttt{G} at type-variable depth \texttt{n}.},
  label={lst:app-lean-typing-basic}
]
inductive Typing : Nat /-$\to$-/ Proc /-$\to$-/ HyperEnv /-$\to$-/ Prop where
  | mix/-$_\texttt{0}$-/ {n : Nat} :
      Typing n /-$\nil$-/ /-$\emptyhyp$-/ 

  | mix {/-$\hyp{G}$-/ /-$\hyp{H}$-/ : HyperEnv} {P Q : Proc} {n : Nat} (hD : /-$\hyp{G}$-/.disjoint /-$\hyp{H}$-/) :
      Typing n P /-$\hyp{G}$-/ /-$\to$-/ Typing n Q /-$\hyp{H}$-/ /-$\to$-/
      Typing n (P /-$\pp_\texttt{p}$-/ Q) (/-$\hyp{G}$-/ /-$\pp_\texttt{h}$-/ /-$\hyp{H}$-/)

  | one {P : Proc} {x : FPName} {n : Nat} :
      Typing n P /-$\emptyhyp$-/ /-$\to$-/
      Typing n (#x/-$\dbrackL$-//-$\dbrackR$-/.P) [[/-$\cht{\texttt{x}}{\texttt{1}}$-/]]

  | bot {/-$\Gamma$-/ : Env} {P : Proc} {x : FPName} {n : Nat} (hF : x /-$\notin$-/ /-$\Gamma$-/.names) :
      Typing n P [/-$\Gamma$-/] /-$\to$-/
      Typing n (#x/-$\dparenL$-//-$\dparenR$-/.P) [/-$\cht{\texttt{x}}{\bot} \texttt{::}\Gamma$-/]

  | cut {/-$\hyp{G}$-/ : HyperEnv} {/-$\Gamma$-/ /-$\Delta$-/ : Env} {P : Proc} {A : Types} {n : Nat} 
    (L : Finset FPName) :
      (/-$\forall$-/ x /-$\notin$-/ L, /-$\forall$-/ y /-$\notin$-/ L, x /-$\neq$-/ y /-$\to$-/
        Typing n (P/-$\dparenL$-/#x, #y/-$\dparenR$-/) (/-$\hyp{G}$-/ /-$\pp_\texttt{h}$-/ [/-$\cht{\texttt{x}}{\texttt{A}} \texttt{::} \Gamma$-/] /-$\pp_\texttt{h}$-/ [/-$\cht{\texttt{y}}{\dual{\texttt{A}}} \texttt{::} \Delta$-/])) /-$\to$-/
      Typing n (/-$\mathit{v}\dparenL$-//-$\bullet$-/,/-$\bullet$-//-$\dparenR$-/ P) (/-$\hyp{G}$-/ /-$\pp_\texttt{h}$-/ [/-$\Gamma$-/,/-$\Delta$-/])

  | tensor {/-$\Gamma$-/ /-$\Delta$-/ : Env} {P : Proc} {x : FPName} {A B : Types} {n : Nat}
      (hF : x /-$\notin$-/ /-$\Gamma$-/.names /-$\land$-/ x /-$\notin$-/ /-$\Delta$-/.names) (L : Finset FPName) :
      (/-$\forall$-/ y /-$\notin$-/ L, Typing n (P/-$\dparenL$-/#y/-$\dparenR$-/) ([/-$\cht{\texttt{y}}{\texttt{A}} \texttt{::} \Gamma$-/] /-$\pp_\texttt{h}$-/ [/-$\cht{\texttt{x}}{\texttt{B}} \texttt{::} \Delta$-/])) /-$\to$-/
      Typing n (#x/-$\dbrackL$-//-$\bullet$-//-$\dbrackR$-/.P) [/-$\cht{\texttt{x}}{\texttt{A}\tensor\texttt{B}} \texttt{::} \Gamma$,$\Delta$-/]

  | parr {/-$\Gamma$-/ : Env} {P : Proc} {x : FPName} {A B : Types}
      {n : Nat} (hF : x /-$\notin$-/ /-$\Gamma$-/.names) (L : Finset FPName) :
      (/-$\forall$-/ y /-$\notin$-/ L, Typing n (P/-$\dparenL$-/#y/-$\dparenR$-/) [/-$\cht{\texttt{y}}{\texttt{A}} \texttt{::} \cht{\texttt{x}}{\texttt{B}} \texttt{::}\Gamma$-/]) /-$\to$-/
      Typing n (#x/-$\dparenL$-//-$\bullet$-//-$\dparenR$-/.P) [/-$\cht{\texttt{x}}{\texttt{A}\parr\texttt{B}} \texttt{::} \Gamma$-/]

  | oplus/-$_\texttt{1}$-/ {/-$\Gamma$-/ : Env} {P : Proc} {x : FPName} {A B : Types} {n : Nat} :
      B.lc n /-$\to$-/ Typing n P [/-$\cht{\texttt{x}}{\texttt{A}} \texttt{::} \Gamma$-/] /-$\to$-/
      Typing n (#x/-$\dbrackL\mathbf{L}\dbrackR$-/.P) [/-$\cht{\texttt{x}}{\texttt{A}\oplus\texttt{B}} \texttt{::} \Gamma$-/]

  | oplus/-$_\texttt{2}$-/ {/-$\Gamma$-/ : Env} {P : Proc} {x : FPName} {A B : Types} {n : Nat} :
      A.lc n /-$\to$-/ Typing n P [/-$\cht{\texttt{x}}{\texttt{B}} \texttt{::} \Gamma$-/] /-$\to$-/
      Typing n (#x/-$\dbrackL\mathbf{R}\dbrackR$-/.P) [/-$\cht{\texttt{x}}{\texttt{A}\oplus\texttt{B}} \texttt{::} \Gamma$-/]

  | amp {/-$\Gamma$-/ : Env} {P Q : Proc} {x : FPName} {A B : Types} {n : Nat} :
      Typing n P [/-$\cht{\texttt{x}}{\texttt{A}} \texttt{::} \Gamma$-/] /-$\to$-/ Typing n Q [/-$\cht{\texttt{x}}{\texttt{B}} \texttt{::} \Gamma$-/] /-$\to$-/
      Typing n (#x.case{/-$\mathbf{L}$-/ : P, /-$\mathbf{R}$-/ : Q}) [/-$\cht{\texttt{x}}{\texttt{A}\:\&\:\texttt{B}} \texttt{::} \Gamma$-/]

  | quest {/-$\Gamma$-/ : Env} {P : Proc} {x : FPName} {A : Types} {n : Nat} :
      Typing n P [/-$\cht{\texttt{x}}{\texttt{A}} \texttt{::} \Gamma$-/] /-$\to$-/
      Typing n (#x/-$\dbrackL\mathbf{USE}\dbrackR$-/.P) [/-$\cht{\texttt{x}}{\texttt{??A}} \texttt{::} \Gamma$-/]

  | bang {/-$\Gamma$-/ : Env} {P : Proc} {x : FPName} {A : Types} {n : Nat} :
      ?/-$_\texttt{e}$-//-$\Gamma$-/ /-$\to$-/ Typing n P [/-$\cht{\texttt{x}}{\texttt{A}} \texttt{::} \Gamma$-/] /-$\to$-/
      Typing n (!#x/-$\langle\Gamma$-/.names.image Channel.free/-$\rangle$-/.{P}) [/-$\cht{\texttt{x}}{\texttt{!!A}} \texttt{::} \Gamma$-/]

  | w {/-$\Gamma$-/ : Env} {P : Proc} {x : FPName} {A : Types} {n : Nat}
      (hF : x /-$\notin$-/ /-$\Gamma$-/.names) :
      A.lc n /-$\to$-/ Typing n P [/-$\Gamma$-/] /-$\to$-/
      Typing n (#x/-$\dbrackL\mathbf{DISP}\dbrackR$-/.P) [/-$\cht{\texttt{x}}{\texttt{??A}} \texttt{::} \Gamma$-/]

  | c {/-$\Gamma$-/ : Env} {P : Proc} {x : FPName} {A : Types} {n : Nat}
      (hF : x /-$\notin$-/ /-$\Gamma$-/.names) (L : Finset FPName) :
      (/-$\forall$-/ y /-$\notin$-/ L, Typing n P/-$\dparenL$-/#y/-$\dparenR$-/ [/-$\cht{\texttt{x}}{\texttt{??A}} \texttt{::} \cht{\texttt{y}}{\texttt{??A}} \texttt{::} \Gamma$-/]) /-$\to$-/
      Typing n (#x/-$\dbrackL$-/DUP/-$\dbrackR$-//-$\dparenL$-//-$\bullet$-//-$\dparenR$-/.P) [/-$\cht{\texttt{x}}{\texttt{??A}} \texttt{::} \Gamma$-/]

  | exists_ {/-$\Gamma$-/ : Env} {P : Proc} {x : FPName} {A B : Types} {n : Nat} :
      A.lc n /-$\to$-/ Typing n P [/-$\cht{\texttt{x}}{\texttt{B\{A // 0\}}} \texttt{::} \Gamma$-/] /-$\to$-/
      Typing n (#x/-$\dbrackL$-/A/-$\dbrackR$-/.P) [/-$\cht{\texttt{x}}{\exists\texttt{.B}} \texttt{::} \Gamma$-/]

  | forall_ {/-$\Gamma$-/ : Env} {P : Proc} {x : FPName} {B : Types} {n : Nat} :
      Typing (n + 1) P [/-$\cht{\texttt{x}}{\texttt{B}} \texttt{::} \Gamma^+$-/] /-$\to$-/
      Typing n (#x/-$\dparenL\diamond\dparenR$-/.P) [/-$\cht{\texttt{x}}{\forall\texttt{.B}} \texttt{::} \Gamma$-/]

  | ax {x y : FPName} {A : Types} {n : Nat} (hneq : x /-$\neq$-/ y) :
      A.lc n /-$\to$-/
      Typing n (#x/-$\:\leftrightarrow_\texttt{p}\:$-/#y) [/-$\cht{\texttt{x}}{\dual{\texttt{A}}} \texttt{::}$-/ [/-$\cht{\texttt{y}}{\texttt{A}}$-/]]

  | exchange_env {/-$\hyp{G}$-/ : HyperEnv} {/-$\Gamma$-/ /-$\Delta$-/ : Env} {P : Proc} {n : Nat} :
      Typing n P (/-$\Gamma \texttt{::}\hyp{G}$-/) /-$\to$-/ /-$\Gamma \sim \Delta$-/ /-$\to$-/
      Typing n P (/-$\Delta \texttt{::}\hyp{G}$-/)

  | exchange_hyper {/-$\hyp{G}$-/ /-$\hyp{H}$-/ : HyperEnv} {P : Proc} {n : Nat} :
      Typing n P /-$\hyp{G}$-/ /-$\to$-/ /-$\hyp{G} \sim \hyp{H}$-/ /-$\to$-/
      Typing n P /-$\hyp{H}$-/

notation:50 n " /-$\vdash$-/ " P " /-$::$-/ " /-$\hyp{G}$-/ => Typing n P /-$\hyp{G}$-/
\end{lstlisting}

\begin{lstlisting}[
  language=Lean4,
  caption={Projection functions from typing derivations. Since the judgement is indexed by both the process and hyperenvironment, these projections simply recover the corresponding indices.},
  label={lst:lean-typing-projections}
]
def proc {/-$\hyp{G}$-/ : HyperEnv} {P : Proc} {n : Nat}
  (_ : n /-$\vdash$-/ P /-$::$-/ /-$\hyp{G}$-/) : Proc := P

def env {/-$\hyp{G}$-/ : HyperEnv} {P : Proc} {n : Nat}
  (_ : n /-$\vdash$-/ P /-$::$-/ /-$\hyp{G}$-/) : HyperEnv := /-$\hyp{G}$-/
\end{lstlisting}

\subsection{Transition Labels}\label{app:labels}
This listing gives the core Lean definitions of the label and action datatypes discussed the paragraph on labels in \cref{subsec:semantics}, together with the associated free-name, introduced-name, and well-formedness functions used by the operational semantics.

\begin{lstlisting}[
    language={Lean4},
    caption={Definitions of transition labels, actions, and their associated free and introduced names.},
    label={lst:lean-label-definitions}
  ]
inductive Mu : Type
  | L
  | R
  | DISP
  | DUP
  | USE
deriving Repr, DecidableEq

inductive Act : Type
  | one       (x : FPName)
  | bot       (x : FPName)
  | tensor    (x y : FPName)
  | parr      (x y : FPName)
  | output    (x : FPName) (A : Types)
  | input     (x : FPName) (A : Types)
  | muBrack   (x : FPName) (/-$\mu$-/ : Mu)
  | muParen   (x : FPName) (/-$\mu$-/ : Mu)
deriving Repr, DecidableEq

inductive Lbl : Type
  | tau
  | link  (x y : FPName)
  | act   (p : Act)
  | par   (l l' : Act)
deriving Repr, DecidableEq

@[simp] def fNamesAct : Act /-$\to$-/ Finset FPName -- free names
  | .one x | .bot x
  | .tensor x _ | .parr x _
  | .input x _ | .output x _
  | .muBrack x _  | .muParen x _ => {x}

@[simp] def iNamesAct : Act /-$\to$-/ Finset FPName -- introduced names
  | .one _ | .bot _ | .input _ _ | .output _ _
  | Act.muBrack _ _ | Act.muParen _ _ => /-$\emptyset$-/
  | .tensor _ y | .parr _ y => {y}

@[simp] def Lbl.f : Lbl /-$\to$-/ Finset FPName
  | .tau        => /-$\emptyset$-/
  | .link x y   => {x, y}
  | .act a      => fNamesAct a
  | .par l l'   => fNamesAct l /-$\cup$-/ fNamesAct l'

@[simp] def Lbl.i : Lbl /-$\to$-/ Finset FPName
  | .tau        => /-$\emptyset$-/
  | .link _ _   => /-$\emptyset$-/
  | .act a      => iNamesAct a
  | .par l l'   => iNamesAct l /-$\cup$-/ iNamesAct l'

@[simp] def Lbl.WF : Lbl /-$\to$-/ Prop
  | .tau => True
  | .link _ _ => True
  | .act _ => True
  | .par l l' => (iNamesAct l) /-$\cap$-/ (iNamesAct l') = /-$\emptyset$-/
\end{lstlisting}

transition relations for \pimll{}, as referenced from

\begin{lstlisting}[language=Lean4,

  label={lst:app-typingstep}]

    {n : Nat} /-$\to$-/ {/-$\hyp{G}$-/ : HyperEnv} /-$\to$-/ {P : Proc} /-$\to$-/ Typing n P /-$\hyp{G}$-/ /-$\to$-/ Lbl /-$\to$-/ 
    {n' : Nat} /-$\to$-/ {/-$\hyp{G}$-/' : HyperEnv} /-$\to$-/ {P' : Proc} /-$\to$-/ Typing n' P' /-$\hyp{G}$-/' /-$\to$-/ Prop where

      TypingStep/-$_\texttt{m}$-/ (Typing.one (x := x) /-$\der{D}$-/) (x/-$\dbrackL\dbrackR$-/) /-$\der{D}$-/
      
  | bot {/-$\Gamma$-/ : Env} {P : Proc} {x : FPName} {n : Nat}
      {hF : /-$ \texttt{x} \notin \Gamma$-/.names} {/-$\der{D}$-/ : Typing n P [/-$\Gamma$-/]} :
      TypingStep/-$_\texttt{m}$-/ (Typing.bot (x := x) hF /-$\der{D}$-/) (x/-$\dparenL\dparenR$-/) /-$\der{D}$-/

  | tensor {/-$\Gamma\ \Delta$-/ : Env} {P : Proc} {x y : FPName} {A B : Types} {n : Nat}
      {hF : /-$\texttt{x} \notin \Gamma\texttt{.names} \land \texttt{x} \notin \Delta$-/.names} {L : Finset FPName}
      {huniq : /-$\forall$-/ z, z /-$\notin$-/ L /-$\to$-/ Typing n (P/-$\dparenL$-/#z/-$\dparenR$-/) ([/-$\cht{\texttt{z}}{\texttt{A}} \texttt{::} \Gamma$-/] /-$\pp_\texttt{h}$-/ [/-$\cht{\texttt{x}}{\texttt{B}} \texttt{::} \Delta$-/])}

      {hF : x /-$\notin$-//-$\Gamma$-/.names} {L : Finset FPName}
      {huniq : /-$\forall$-/ z, z /-$\notin$-/ L /-$\to$-/ Typing n (P/-$\dparenL$-/#z/-$\dparenR$-/) [z /-$\colon$-/A::x /-$\colon$-/B::/-$\Gamma$-/]}
      {hy : y /-$\notin$-/({x} /-$\cup$-/ P.f /-$\cup$-//-$\Gamma$-/.names)} :
      TypingStep/-$_\texttt{m}$-/ (Typing.parr hF L huniq) (x/-$\dparenL$-/y/-$\dparenR$-/) (Typing_parr_all_fresh huniq y hy)

  | par/-$_1$-/ {/-$\hyp{G}\ \hyp{H}\ \hyp{G}'$-/ : HyperEnv} {P Q P' : Proc} {l : Lbl} {n : Nat}

      {/-$\der{D}$-/ : Typing n P /-$\hyp{G}$-/} {/-$\der{D}$-/' : Typing n P' /-$\hyp{G}'$-/} {/-$\der{E}$-/ : Typing n Q /-$\hyp{H}$-/}
      (h : TypingStep/-$_\texttt{m}$-/ /-$\der{D}$-/ l /-$\der{D}$-/') (disj : l.i /-$\cap$-/ Q.f = /-$\emptyset$-/) :
      TypingStep/-$_\texttt{m}$-/ (Typing.mix hD1 /-$\der{D}\ \der{E}$-/) l (Typing.mix hD2 /-$\der{D}'\ \der{E}$-/)

  | par/-$_2$-/ {/-$\hyp{G}\ \hyp{H}\ \hyp{H}'$-/ : HyperEnv} {P Q Q' : Proc} {l : Lbl} {n : Nat}
      {hD1 : /-$\hyp{G}$-/.disjoint /-$\hyp{H}$-/} {hD2 : /-$\hyp{G}$-/.disjoint /-$\hyp{H}'$-/}
      {/-$\der{D}$-/ : Typing n P /-$\hyp{G}$-/} {/-$\der{E}$-/ : Typing n Q /-$\hyp{H}$-/} {/-$\der{E}$-/' : Typing n Q' /-$\hyp{H}'$-/}
      (h : TypingStep/-$_\texttt{m}$-/ /-$\der{E}$-/ l /-$\der{E}$-/') (disj : l.i /-$\cap$-/ P.f = /-$\emptyset$-/) :
      TypingStep/-$_\texttt{m}$-/ (Typing.mix hD1 /-$\der{D}\ \der{E}$-/) l (Typing.mix hD2 /-$\der{D}\ \der{E}$-/')

  | syn {/-$\hyp{G}\ \hyp{G}'\ \hyp{H}\ \hyp{H}'$-/ : HyperEnv} {P P' Q Q' : Proc} {l l' : Act} {n : Nat}
      {hD1 : /-$\hyp{G}$-/.disjoint /-$\hyp{H}$-/} {hD2 : /-$\hyp{G}'$-/.disjoint /-$\hyp{H}'$-/}
      {/-$\der{D}$-/ : Typing n P /-$\hyp{G}$-/} {/-$\der{D}$-/' : Typing n P' /-$\hyp{G}'$-/}
      {/-$\der{E}$-/ : Typing n Q /-$\hyp{H}$-/} {/-$\der{E}$-/' : Typing n Q' /-$\hyp{H}'$-/}
      (h/-$_1$-/ : TypingStep/-$_\texttt{m}$-/ /-$\der{D}$-/ l /-$\der{D}$-/') (h/-$_2$-/ : TypingStep/-$_\texttt{m}$-/ /-$\der{E}$-/ l' /-$\der{E}$-/')
      (disj : (l /-$\pp_\texttt{l}$-/ l').i /-$\cap$-/ (P /-$\pp_\texttt{p}$-/ Q).f = /-$\emptyset$-/) (WF : (l /-$\pp_\texttt{l}$-/ l').WF) :
      TypingStep/-$_\texttt{m}$-/ (Typing.mix hD1 /-$\der{D}\ \der{E}$-/) (l /-$\pp_\texttt{l}$-/ l') (Typing.mix hD2 /-$\der{D}'\ \der{E}$-/')

  | one_bot {/-$\hyp{G}$-/ : HyperEnv} {/-$\Gamma$-/ : Env} {P P' : Proc} {n : Nat} {L : Finset FPName}
      {huniq : /-$\forall$-/ x /-$\notin$-/ L, /-$\forall$-/ y /-$\notin$-/ L, x /-$\neq$-/ y /-$\to$-/
        Typing n (P/-$\dparenL$-/#x, #y/-$\dparenR$-/) (/-$\hyp{G}\ \pp_\texttt{h}$-/ [/-$\cht{\texttt{x}}{\texttt{1}} \texttt{::} \emptyhyp$-/] /-$\pp_\texttt{h}$-/ [/-$\cht{\texttt{y}}{\bot} \texttt{::} \Gamma$-/])}
      {x y : FPName}
      {hx : x /-$\notin$-/ ({y} /-$\cup$-/ P.f /-$\cup$-/ /-$\hyp{G}$-/.names /-$\cup$-/ /-$\Gamma$-/.names)}
      {hy : y /-$\notin$-/ (P.f /-$\cup$-/ /-$\hyp{G}$-/.names /-$\cup$-/ /-$\Gamma$-/.names)}
      {/-$\der{D}$-/' : Typing n P' (/-$\hyp{G}\ \pp_\texttt{h}$-/ [/-$\emptyhyp\texttt{,}\Gamma$-/])}
      (hStep : TypingStep/-$_\texttt{m}$-/ (Typing_one_bot_all_fresh huniq x y hx hy)
        (/-$\dlsend{\texttt{x}}{} \pp_\texttt{l} \dlrecv{\texttt{y}}{}$-/) /-$\der{D}$-/') :

  | tensor_parr {/-$\hyp{G}$-/ : HyperEnv} {/-$\Gamma\ \Delta\ \Xi$-/ : Env} {P P' : Proc} {A B : Types} 
      {n : Nat} {L : Finset FPName}
      {huniq : /-$\forall$-/ x /-$\notin$-/ L, /-$\forall$-/ y /-$\notin$-/ L, x /-$\neq$-/ y /-$\to$-/

\paragraph{Typing inversion}
Inversion lemmas recover the typing rule used to derive a given judgement. They are used throughout the typability proof to identify the typing rule compatible with the observed process shape.

The proofs proceed by induction on the typing derivation after first generalising the concrete process shape. All constructors whose conclusion cannot have the required process form are discharged by contradiction. The matching constructor case then uses injectivity of the process and channel constructors to recover the equalities between the displayed process and the process appearing in the typing derivation. For \texttt{Typing\_inv\_one}, this directly yields the empty continuation typing premise and a permutation showing that the hyperenvironment contains exactly the singleton environment for \texttt{x}. For \texttt{Typing\_inv\_tensor}, the matching case additionally exposes the hidden types, component environments, and co-finite premise of the original \texttt{tensor} rule. The exchange cases propagate the inversion result through environment and hyperenvironment permutation, composing the recovered permutation with the exchange permutation introduced by the typing derivation.

\paragraph{Hyperenvironment extraction}
Extraction lemmas isolate specific components from a hyperenvironment permutation, exposing the typing environment required for a particular transition case. The following statement is representative of the extraction lemmas used when reconstructing a \path{tensor\_parr} synchronisation beneath an enclosing restriction in the proof of \path{typability\_subject\_reduction}$_\texttt{m}$. The proof proceeds by extracting component membership from the pre-transition permutation, followed by case analysis on the relative positions of the restricted endpoints. Freshness and inequality assumptions rule out impossible coincidences, while the valid branches reconstruct the resulting hyperenvironment permutations using permutation rotation, merge, and cancellation lemmas.

\paragraph{Block preservation lemmas.}
The following lemmas establish that environment components not involved in a transition persist in the post-state hyperenvironment up to permutation. The fully proved lemma \texttt{TypingStep}$_{\texttt{m}}$\texttt{\_preserves\_block} states that any component whose names are disjoint from the label survives the transition. Building on this, \texttt{TypingStep}$_{\texttt{m}}$\texttt{\_preserves\_single\_block} tracks a specific component carrying a distinguished endpoint through a transition, with its remaining proof obligations confined to its \texttt{res} case. The lemma \texttt{TypingStep}$_{\texttt{m}}$\texttt{\_preserves\_disjoint\_or\_merges} simultaneously tracks two dual endpoint components, concluding either that they remain in separate post-state components or that they have been merged into one. This disjunction captures the two structural configurations that may result from stepping beneath a restriction, and is intended to provide the post-transition hyperenvironment structure needed to complete the \texttt{res} case of \texttt{typability\_subject\_reduction}$_{\texttt{m}}$ by rebuilding the outer \texttt{cut} derivation. The proofs proceed by induction on the typed transition derivation, transporting unaffected components directly or through permutation and applying the induction hypothesis to components in an evolving branch. In the nested restriction argument, the stronger lemmas additionally rely on the completed block-preservation result to recover endpoint-bearing components beneath the inner transition.
